{% comment %} Menu que cambia segun haya sesion. user.is_authenticated es verdadero si el usuario inicio sesion. El cierre de sesion lo hago con un formulario POST y no con un enlace, porque un enlace es GET y cualquier pagina podria cerrarle la sesion al usuario solo con poner ese enlace en una imagen. Con POST el formulario lleva el csrf_token y Django revisa que venga de mi propio sitio. {% endcomment %}
